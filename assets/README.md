# Assets

Copied next to the game executable on every build (see CMakeLists.txt).

| File | Source | Used for |
|---|---|---|
| `textures/paving_color.jpg`, `textures/paving_ao.jpg` | ambientCG PavingStones151 (1K-JPG), CC0 | Ground and walls ("concrete") |
| `textures/paving_normal.jpg`, `textures/paving_roughness.jpg` | same pack | Normal and roughness maps for the lit shader |
| `textures/steel_color.jpg`, `textures/steel_ao.jpg` | ambientCG CorrugatedSteel007B (1K-JPG), CC0 | Cover boxes |
| `textures/steel_normal.jpg`, `textures/steel_roughness.jpg` | same pack | Normal and roughness maps for the lit shader |
| `textures/{plaster,sandstone,planks,crate,sand}_{color,normal,rough}.png` | generated by `tools/make_textures.py` (made for this project) | The town: plastered buildings (chipped to brick), sandstone blocks, planks (terrace, doors, painted shutters), crates, sand |
| `shaders/lit.vs`, `lit.fs`, `sky.fs` | written for this project | Sun + sky lighting, shadows, normal maps, fog, tonemapping; the sky |
| `sounds/wind.wav` | generated by `tools/make_ambience.py` | Ambient wind loop |
| `models/revolver/revolver.glb`, `revolver.txt`, `*.png` | built by `tools/make_revolver.py` (made for this project) | The revolver: first person, the enemy's, cartridges, cases and the speedloader |
| `models/character/character.glb`, `character.txt` | `civil+man+blend.rar` (Citizen.blend), converted by `tools/export_character.py` | The enemy, your own body (legs) and your first-person arms |
| `sounds/gunshot.mp3` | `freesound_community-single-pistol-gunshot-33-37187.mp3` | Every shot (yours, and the enemy's by distance and direction) |
| `sounds/reload.mp3` | `freesound_community-clean-revolver-reload-6889.mp3` | Reloading (cut into its clicks at load, see below) |
| `sounds/walk.mp3` | `freesound_community-walking-96582.mp3` | Footsteps: walking (and quieter/slower crouch-walking) |
| `sounds/run.mp3` | `freeeverythingxx-running-on-concrete-268478.mp3` | Footsteps: sprinting |

AO is multiplied into the color at load; normal and roughness maps feed the lit
shader. Impact, hit, headshot, kill, dry-fire, hurt, landing and bullet-crack sounds
are synthesized at startup in `src/audio.cpp` (no files), as are the brass cases'
tinks. Sounds are trimmed of leading (and, for the footstep loops, trailing) silence
and level-matched at load (see `src/audio.cpp`); the files themselves are unedited.
The reload recording is cut at load into its separate sounds (latch, cylinder out,
ejection, rounds in, spin, cylinder shut), each played on its moment in the reload
animation.

The map's building textures are generated too (Blender's bundled numpy):

    blender --background --factory-startup --python tools/make_textures.py -- assets/textures

The revolver is built procedurally in Blender: a six-shot, double-action, swing-out
revolver made of separate moving parts (frame, grip, cylinder, crane, ejector rod and
star, hammer, trigger, latch) plus cartridges, fired cases and a speedloader, with
generated steel and checkered-walnut textures. `revolver.txt` lists the meshes and the
pivots the game animates them about. To regenerate (Blender 4.x):

    blender --background --factory-startup --python tools/make_revolver.py -- assets/models/revolver

The character came without animations; `tools/export_character.py` authors them
(idle, walk, run, crouch, crouch_walk, rest, and the first-person fp_hold, which includes
the revolver's reload: the right hand carries the gun through it and the left hand works
the latch, ejector, speedloader and cylinder) and splits the mesh into parts. It reads
`models/revolver/revolver.txt`, so build the revolver first. To regenerate after editing the script (Blender 4.x):

    blender --background --disable-autoexec Citizen.blend --python tools/export_character.py -- <Citizen textures dir> assets/models/character
